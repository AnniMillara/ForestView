¿Qué es ForestGuard?

ForestGuard es un sistema de monitoreo ambiental diseñado para detectar tempranamente condiciones compatibles con incendios forestales. Utiliza estaciones ESP32 equipadas con sensores DHT22 (temperatura y humedad) y MQ-2 (detección de humo/gases).

¿Cómo funciona?

  1. La ESP32 mide temperatura, humedad y humo.
  2. Envía los datos por WiFi a la aplicación Flask mediante HTTP POST.
  3. Flask valida la estación, guarda la medición en MySQL y evalúa el riesgo combinando las variables.
  4. Si se detecta una situación de riesgo, se genera una alerta que aparece en el dashboard.
  5. Los usuarios autorizados pueden visualizar, atender y resolver alertas.

Conectar una ESP32

  1. Configura el firmware ForestGuard_ESP32.ino con tu SSID, contraseña WiFi, la IP de tu PC donde corre Flask y el código y API key de la estación (regístrala primero en la sección Estaciones).
  2. Carga el firmware en la ESP32 con Arduino IDE.
  3. La ESP32 comenzará a enviar datos cada 5 segundos. Verifica en el monitor serie que obtiene una IP y que el HTTP devuelve 200 OK.
  4. En el dashboard, la estación aparecerá como ONLINE y mostrará los datos.

Interpretación de datos

  • Temperatura: < 30°C Normal, 30-35°C Elevada, ≥35°C Crítica.
  • Humedad: > 45% Normal, 30-45% Baja, ≤30% Crítica.
  • Humo: NINGUNO, BAJO, MEDIO, ALTO (según cambio del AO respecto a la línea base).
  • Niveles de riesgo: NORMAL (verde), RIESGO_MODERADO (amarillo), RIESGO_ALTO (naranja), ALERTA (rojo).

Roles y permisos

  • ADMINISTRADOR: Control total: usuarios, estaciones, configuración, alertas.
  • BOMBERO: Puede atender y resolver alertas, ver todos los datos.
  • OPERADOR: Monitoreo y gestión de alertas, sin administración de usuarios ni configuración.
  • OBSERVADOR: Solo visualización de datos, sin acciones operativas.
¡Importante! Una alerta de ForestGuard no reemplaza la evaluación profesional ni autoriza a personas no capacitadas a acercarse a un incendio. Ante una alerta, contacte a los servicios de emergencia oficiales.
