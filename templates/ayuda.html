Qué es ForestGuard y ForestView

ForestGuard y ForestView son dos partes de un mismo sistema de monitoreo ambiental. Funcionan como compañeros: uno no puede funcionar sin el otro.

ForestGuard

Es el sistema de sensores. Está formado por dispositivos ESP32 equipados con sensores DHT22 (temperatura y humedad) y MQ-2 (detección de humo y gases). Su trabajo es medir las condiciones ambientales en el campo y enviar los datos a la plataforma web.

ForestView

Es la plataforma web que recibe, almacena y visualiza los datos de todas las estaciones ForestGuard. Permite ver el estado de las zonas monitoreadas, gestionar alertas y tomar decisiones informadas.

Sin ForestGuard no hay datos que mostrar en ForestView. Sin ForestView no hay forma de ver ni gestionar los datos que ForestGuard recolecta. Trabajan juntos para proteger el entorno.

Cómo funciona el sistema

El flujo completo es sencillo y automático:

  1. ForestGuard (ESP32) mide temperatura, humedad y nivel de humo cada pocos segundos.
  2. Los datos se envían por WiFi a ForestView mediante una solicitud HTTP.
  3. ForestView recibe los datos, los guarda en una base de datos y analiza las condiciones.
  4. Si se detecta una situación de riesgo, ForestView genera una alerta automáticamente.
  5. Tú, como usuario, ves toda la información en el Dashboard de ForestView y puedes actuar en consecuencia.

Nota: Todo este proceso ocurre en tiempo real, sin intervención manual.

El Dashboard de ForestView

Al iniciar sesión, entras al Dashboard. Es el centro de operaciones donde puedes ver todo de un vistazo:

Estadísticas

Temperatura, humedad, humo y riesgo actual del sistema.

Mapa interactivo

Cada punto en el mapa es una estación ForestGuard. Su color indica el nivel de riesgo.

Alertas recientes

Las últimas alertas generadas. Acceso rápido al historial completo.

Estado de sensores

Indica si las estaciones están conectadas (Online) o sin comunicación (Offline).

Interpretación de los datos

Cada estación ForestGuard mide tres variables. Los colores te ayudan a identificar rápidamente el nivel de alerta:

Temperatura Normal: bajo 30°C Elevada: 30‑35°C Crítica: sobre 35°C
Humedad Normal: sobre 45% Baja: 30‑45% Crítica: bajo 30%
Nivel de humo NINGUNO BAJO MEDIO ALTO

Niveles de riesgo (combinación de todo)

NORMAL RIESGO MODERADO RIESGO ALTO ALERTA

Nota: Una alerta roja no significa que hay un incendio, pero sí que las condiciones son preocupantes y requieren atención inmediata.

Alertas: procedimiento recomendado

Cuando una estación ForestGuard detecta condiciones anormales, ForestView genera una alerta. Aparecerá en el Dashboard y en la sección Alertas.

Pasos recomendados

  1. Revisar la alerta: Leer el título y la descripción para saber qué estación la generó y qué parámetro está fuera de rango.
  2. Confirmar recepción: Si eres operador o bombero, haz clic en "Atender" para indicar que estás al tanto de la situación.
  3. Actuar según corresponda: Si es una falsa alarma, márcala como "Falsa". Si la situación está controlada, márcala como "Resuelta".
  4. Consultar historial: Las alertas resueltas quedan registradas para futuras consultas y análisis.
Importante: Si ves una alerta de nivel ALERTA y no estás capacitado para actuar, contacta inmediatamente a los servicios de emergencia. ForestView es una herramienta de apoyo, no reemplaza a los bomberos.

Gestión de estaciones ForestGuard

Desde el menú Estaciones (solo visible para administradores) puedes gestionar los dispositivos ForestGuard instalados en el campo.

  • Registrar una nueva estación: Ve a Estaciones → Nueva estación. Necesitarás el código y la API key que la ESP32 usará para identificarse.
  • Consultar estado: En la lista verás si están Online (conectadas) o Offline (sin comunicación reciente).
  • Editar o desactivar: Puedes modificar su ubicación o desactivarla si ya no se utiliza.

Consejo: Si una estación aparece Offline, comprueba que tenga alimentación eléctrica y conexión WiFi. A veces basta con reiniciarla.

Roles de usuario

Cada usuario de ForestView tiene un rol que determina lo que puede hacer dentro de la plataforma:

Rol Permisos
Administrador Control total: gestión de usuarios, estaciones, configuración, alertas y acceso a todas las secciones.
Bombero Puede ver el mapa, las estaciones y atender/resolver alertas. No puede crear usuarios ni modificar la configuración del sistema.
Operador Monitorea el sistema, visualiza todas las estaciones y alertas, y puede confirmar y asignar alertas. No puede modificar usuarios ni configuración.
Observador Solo visualización: puede ver el Dashboard, el mapa y las alertas, pero no puede modificarlas ni gestionar estaciones.

Nota: Si necesitas cambiar tu rol, contacta con el administrador del sistema.

Consejos para usar ForestView

  • Activa las notificaciones: En Configuración puedes activar las notificaciones del navegador para recibir alertas en tiempo real sin estar mirando la pantalla.
  • Comparte tu ubicación: Si activas la opción de ubicación, las alertas te mostrarán la distancia a la estación afectada, lo que ayuda a priorizar respuestas.
  • Usa los filtros: En el historial y en la sección de alertas puedes filtrar por estación, fecha o nivel de riesgo para encontrar información rápidamente.
  • Revisa el historial: Los datos históricos te ayudan a identificar tendencias y anticipar posibles problemas antes de que se conviertan en emergencias.
  • Actualiza la página: Si notas que los datos no se actualizan, presiona Ctrl+F5 para recargar completamente la página y limpiar la caché.

¿Necesitas ayuda?

Si tienes dudas sobre el funcionamiento de ForestView o encuentras algún error, contacta con el administrador del sistema.
